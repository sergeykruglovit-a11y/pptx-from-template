# Инструкция для ИИ-агента: презентация в шаблоне пользователя

Пользователь даёт **шаблон презентации (.pptx)** и **готовое содержание** (текст, документ, тезисы). Ты раскладываешь
содержание по макетам шаблона и собираешь `.pptx` скриптами этого репозитория. Оформление целиком берётся из
шаблона: ты не рисуешь слайды и не выбираешь цвета/шрифты. Не придумывай фактов и цифр.

## 0. Что нужно от пользователя — проверь ДО любой работы

- **Шаблон .pptx** — приложенный файл. Нет шаблона — попроси приложить и остановись.
  Шаблон в .potx / .odp / .key — сначала `soffice --headless --convert-to pptx <файл>`.
- **Содержание** — текст в сообщении пользователя или **отдельные** файлы помимо шаблона (docx, pdf, txt, md,
  другой pptx — прочитай их).
- **Текст на слайдах шаблона — это образцы оформления, а НЕ содержание.** Никогда не собирай презентацию из
  текста самого шаблона, даже если он выглядит как готовая презентация.
- Если пользователь прислал только шаблон (кроме него — лишь эта просьба, без своего текста и файлов) или
  содержания явно мало — **ничего не запускай**: ответь одним сообщением «Пришлите, пожалуйста, содержание
  презентации — текстом в чат или файлом (Word, PDF, текст)» и остановись. Продолжай, когда содержание придёт.

## 1. Подготовка

```bash
git clone --depth 1 https://github.com/sergeykruglovit-a11y/pptx-from-template.git
# или: curl -L -o r.zip https://github.com/sergeykruglovit-a11y/pptx-from-template/archive/refs/heads/main.zip && unzip r.zip
cd pptx-from-template
python3 -c "import pptx" 2>/dev/null || pip install python-pptx
```
Не скачивается (нет интернета) — попроси пользователя приложить архив репозитория (Code → Download ZIP).

## 2. Разбери шаблон

```bash
python3 analyze.py "<шаблон>.pptx" -o work/layouts.json --render
python3 build.py --layouts work/layouts.json --catalog
```
- `analyze.py` находит макеты шаблона, их поля и лимиты знаков. С `--render` рисует карту макетов
  `work/layouts-map/layouts-map.jpg`, где на каждом поле подписан его ключ. **Посмотри её**, если умеешь смотреть
  картинки: так ты поймёшь, для чего каждый макет.
- Если `analyze.py` пишет «ВНИМАНИЕ: фирменный дизайн нарисован прямо на слайдах», значит, шаблон сделан без
  макетов, и сборка по макетам даст безликие слайды. Скажи об этом пользователю и предложи один из вариантов:
  (а) дизайнер переносит оформление в «Образец слайдов» (Вид → Образец слайдов), и тогда сборка работает отлично;
  (б) сборка клонированием слайдов шаблона инструментом https://github.com/sergeykruglovit-a11y/owui-pptx-kit
  (см. его README и `skills/pptx-restyle.md`).
- Можно уточнить `work/layouts.json`: поправить описания `use`, названия полей, лимиты; убрать макеты, которые не
  нужны. Формат полей не меняй.

## 3. Разложи содержание → `work/content.json`

- Каждый слайд — `{"layout": "<точное имя макета>", <поля макета>}`. Ключи полей — как в `--catalog`
  (`title`, `subtitle`, `body`, `body2`, `image`, `table`…). Для макетов с группой элементов (колонки, карточки,
  плитки) — список `"items": [{"title": "…", "text": "…"}, …]` в пределах min–max.
- Поле-список: `["пункт", "пункт", {"text": "подпункт", "level": 1}]`.
- Таблица: `"table": {"header": ["…"], "rows": [["…"]]}`. Картинка: `"image": "путь/к/файлу"`.
- Заметки докладчика: `"notes": "…"`.
- Первый слайд — титульный макет, последний — финальный, если такие есть. Не больше трёх слайдов подряд на одном
  макете. Три параллельных пункта — в карточки, сравнение — в колонки, показатели — в плитки, если такие макеты есть.
- Всё содержание пользователя должно попасть на слайды. Сокращай формулировки, но не факты. Не влезает — раздели
  на два слайда. Содержание слайда в заметки не переноси.

Пример формата — `examples/content-example.json`.

## 4. Проверь и собери

```bash
python3 build.py --layouts work/layouts.json --check work/content.json
python3 build.py work/content.json --template "<шаблон>.pptx" --layouts work/layouts.json -o "<Название>.pptx" --render
```
- `ОШИБКА` — исправь content.json. `ВНИМАНИЕ` / `ПЕРЕПОЛНЕНИЕ` — сократи или разбей, пересобери.
- Если есть превью (`…_preview/contact.jpg`), посмотри его: текст не налезает, содержание на месте, нет однообразия.
  Превью рисует LibreOffice: подсказки пустых полей макета (например, текст-заглушка в неиспользованной плитке) там
  видны, а в PowerPoint — нет. Это не исправляй.
- Слайды-примеры из шаблона в результат не попадают: собирается новая презентация на макетах шаблона.

## 5. Отдай результат

- Сохрани `.pptx` туда, откуда пользователь сможет его скачать (в ChatGPT — `/mnt/data/`, в Claude — папка для
  выходных файлов), дай ссылку и покажи `contact.jpg`, если есть.
- Коротко: сколько слайдов, какие макеты, что сокращено или разбито, что сделать руками (вставить фото, проверить
  цифры). Если шаблон без макетов (шаг 2) — честно скажи, что результат ограничен.
- Предложи сохранить `work/layouts.json`: с ним в следующий раз шаг 2 не нужен.
