# Презентация в вашем шаблоне — для ИИ-агентов

> **ИИ-агенту:** твоя инструкция — [AGENTS.md](AGENTS.md).

Агент (ChatGPT, Claude и другие, которые умеют запускать код) скачивает этот репозиторий, разбирает **ваш**
корпоративный шаблон .pptx, раскладывает **ваше** готовое содержание по его макетам и собирает презентацию.
Оформление целиком из шаблона — агент ничего не рисует сам.

## Как пользоваться

Приложите к чату шаблон .pptx **и своё содержание** — отдельным файлом или текстом в том же сообщении — и напишите:

> Скачай https://github.com/sergeykruglovit-a11y/pptx-from-template и выполни AGENTS.md — собери из моего содержания презентацию в приложенном шаблоне и дай ссылку на .pptx.

Текст на слайдах шаблона агент содержанием не считает: если прислать только шаблон, он попросит содержание.

Если агент не может скачать репозиторий: **Code → Download ZIP** на этой странице, приложите архив к чату.

## Какой шаблон подходит

Лучше всего — шаблон, где фирменное оформление сделано в **макетах** («Вид → Образец слайдов»): титульный, раздел,
заголовок и текст, колонки, карточки, цифры, финал — с полями-плейсхолдерами. Тогда каждый новый слайд получается
фирменным автоматически.

Если дизайн нарисован прямо на слайдах (картинка-фон, текстовые поля поверх), `analyze.py` об этом предупредит:
такой шаблон стоит один раз переделать в макеты или собирать клонированием слайдов
([owui-pptx-kit](https://github.com/sergeykruglovit-a11y/owui-pptx-kit)).

## Что внутри

| Файл | Зачем |
|---|---|
| `AGENTS.md` | инструкция для ИИ-агента |
| `analyze.py` | разбирает шаблон: макеты, поля, лимиты знаков → `layouts.json`; рисует карту макетов |
| `build.py` | проверяет содержание и собирает .pptx на макетах шаблона; превью и проверка переполнения |
| `examples/content-example.json` | пример формата содержания |

Вручную (нужен Python и `pip install python-pptx`; для превью — LibreOffice):

```bash
python3 analyze.py шаблон.pptx -o work/layouts.json --render
python3 build.py --layouts work/layouts.json --catalog
python3 build.py content.json --template шаблон.pptx --layouts work/layouts.json -o result.pptx --render
```

Готовый вариант под конкретный шаблон с выверенным каталогом:
[vitomek-slides](https://github.com/sergeykruglovit-a11y/vitomek-slides).
